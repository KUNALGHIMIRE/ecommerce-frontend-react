# 👟 Shoe Store - E-Commerce Frontend

A shoe shopping website where users can browse and buy shoes.

## Live Demo

[https://ecommerce-frontend-reacta.onrender.com](https://ecommerce-frontend-reacta.onrender.com)

## Features

- Product listing (shoes)
- Category filter
- Login page
- About, Location, Contact pages
- Shop button

## Tech Stack

- React
- CSS
- Vite

## Run Locally

```bash
npm install
npm run dev
